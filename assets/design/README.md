# Design assets (T8 input)

Drop files here; the planner inspects them before the T8 brief is written.

- `themes/`   — theme design JSON + its MD instruction file (one theme per entry; the
                game will offer a theme picker built from this catalog)
- `squishes/` — squish catalog JSON + MD instruction file + example PNG(s)
                (16 squishes to start; the catalog is meant to grow)

Both catalogs are editable by hand to add themes/squishes without code changes.
Assets must be original or clearly licensed (D-018 note applies).
